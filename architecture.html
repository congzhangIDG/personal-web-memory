Personal Web Memory 系统架构

Chrome 扩展 + Next.js 服务端 · 左—右数据流：本地采集 → HTTP 上传 → 服务端处理与存储

📦 本地采集层 (Extension)

  • • 内容脚本提取 DOM innerText，减少服务端请求
  • • Background 事件驱动计时：活跃/失焦/关闭全场景覆盖
  • • Dexie IndexedDB 本地持久化，纯离线可用
  • • Alarm 定时聚合上传（默认每 5 分钟）
  • • Options 配置页：API 地址、上传开关、黑名单

🌐 服务端处理层 (Next.js + Prisma)

  • • 接收 DailyDigest，upsert 策略防重复叠加
  • • 页面文本持久化到 content/{date}/{id}.txt
  • • AI 摘要：LLM（OpenAI 兼容）→ 规则兜底，失败不报错
  • • 主题标签：LLM 批量生成 → 域名映射表 + 标题关键词
  • • 系统设置 1 分钟内存缓存，修改后自动失效

📊 数据流概览

  • • 扩展端：Content → Background → Dexie → Aggregator → Uploader
  • • 网络：HTTP POST /api/digest（仅上传聚合摘要）
  • • 服务端：API → 落库 + 写文件 → AI 补全 → 更新 DB
  • • Dashboard：直接读 Prisma（不绕内部 HTTP）
  • • 共享契约 @pwm/shared：Zod Schema 前后端统一
